# 随机有数 · 转盘抽签

一个无需后端的中文抽签网站。Windows、macOS 的现代浏览器均可访问。Excel 解析组件已随站点打包，名单不会发送到服务器。

## 使用

1. 准备 Excel，每行一个十位编号，建议将编号列设置为“文本”，保留开头的 0。
2. 点击“导入 Excel 名单”，选择工作表和编号列。支持 `.xlsx`、`.xls`、UTF-8 `.csv`，会显示有效、重复和无效内容。
3. 点击“开始抽签”，每轮转动 5.6–6.8 秒。所有待抽编号等概率；动画模拟加速和减速，不使用真实刚体物理引擎。
4. 本轮抽中的编号停留在转盘上，下一轮开始时移除，其他格子等面积重排。
5. 右上角“撤销一步”仅撤销最近一轮，使用后不能继续撤销更早结果。
6. 点击“保存进度”保存本轮。每次打开或刷新网址默认都是全新的空白抽签页面；需要继续时，在同一浏览器点击“恢复已保存进度”。

保存使用浏览器 localStorage，不跨电脑同步。清理网站数据、使用无痕窗口或更换域名会影响恢复。Excel 已经丢失的前导零无法自动推断；按文本保存或使用十位显示格式后再导入。每份文件最多 20 MB，最多 10,000 个有效编号。人数很多时全部格子仍保留，但转盘文字会变小，可从下方显示器查看当前编号。

## 本地与部署

直接打开 `dist/index.html` 可以运行；建议使用网站地址以获得稳定的浏览器保存行为。开发预览：`npm start`。逻辑检查：`npm test`。

`dist/` 为完整静态站点目录，可部署到静态网站托管服务，也可以复制给其他电脑离线使用。示例 Excel 为 `dist/示例名单.xlsx`。

Excel 组件：[SheetJS Community Edition 0.20.3](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)，Apache-2.0 许可证，源文件头保留原作者声明。

## GitHub Pages

发布目录为 `dist/`。仓库 Settings → Pages → Source 选择 GitHub Actions。推送到 main 分支后自动检查并发布。所有脚本均使用相对路径，支持 GitHub Pages 仓库子路径。

每次打开或刷新默认是空白抽签页。所有名单和存档留在访问者自己的浏览器内，不上传到 GitHub。
